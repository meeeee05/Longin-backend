## 概要

本リポジトリでは、スキャフォールド機能を用いてログイン機能を有するWeb APIを構築したものです。 

Next.js などで作成したフロントエンドと連携することで、  
ログイン機能のあるWebアプリを構築できます。

本システムの構築手順や実装のポイントは、以下の記事で解説しています。

[【Next.js】【Rails】ログイン画面とAPIを作ってみる①（Backend作成編）](https://zenn.dev/eeeee05/articles/132c18e354bded)

## 主な機能

- ユーザー登録 / ログイン / ログアウト
- APIによるフロントエンド分離構成


## 技術スタック

- Ruby 3.4.4
- Rails 8.0.3
- SQLite3（デフォルトDB）
